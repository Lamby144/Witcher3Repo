# Witcher 3 – Ultimate Platinum Checklist

A simple GitHub Pages checklist for a full Witcher 3 platinum run, including a full Gwent card checklist.

## Setup
1. Put the files in the repo root.
2. Download `cards.json` and save it as `data/cards.json` from:
   https://gwentcards.github.io/cards.json

## GitHub Pages
Settings → Pages → Deploy from branch → main / root

## Backup your progress
Use the **Export Save** button to download your progress.
Use **Import Save** to restore it on another device.

## Notes
Tick-box state is stored in your browser localStorage.
